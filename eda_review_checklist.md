# EDA Review Checklist

Before sharing an exploratory analysis, I check:

- [ ] Confirm the dataset shape, row grain, and column types.
- [ ] Review missing values and duplicate records.
- [ ] Validate units, date ranges, and category labels.
- [ ] Inspect distributions before choosing summary statistics.
- [ ] Check whether outliers are errors or valid observations.
- [ ] Label charts clearly and include units where relevant.
- [ ] Separate observed patterns from assumptions or causal claims.
- [ ] Record the dataset source and any cleaning decisions.

This checklist is a final review aid; it does not replace domain-specific validation.
